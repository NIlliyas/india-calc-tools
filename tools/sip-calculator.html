How SIP returns are estimated

A SIP (Systematic Investment Plan) invests a fixed amount every month, usually in a mutual fund. This calculator estimates the future value using this formula:

Future value = P × ((1 + i)n − 1) ÷ i × (1 + i)

Here P is the monthly amount, i is the monthly return rate (yearly rate ÷ 12 ÷ 100), and n is the total number of months.

Important: Mutual fund returns are not guaranteed and change with the market. The result is only an estimate for planning, not financial advice. Please read the scheme documents or speak to a SEBI-registered advisor before investing.
